# Resume Builder

A simple, ATS-friendly resume builder that converts HTML resumes to PDF format.

## Features

- Clean, professional resume template
- ATS-optimized formatting
- Single-page layout
- Easy PDF conversion
- Consistent styling

## Requirements

- Python 3.6+
- WeasyPrint

## Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/resume-builder.git
cd resume-builder
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

## Usage

1. Edit `resume.html` with your information
2. Run the conversion script:
```bash
python convert_to_pdf.py
```

## Project Structure

- `resume.html` - Main resume template
- `convert_to_pdf.py` - PDF conversion script
- `requirements.txt` - Python dependencies

## Formatting Guidelines

- A4 page size with 2.54cm margins
- Arial font family
- Single column layout
- Left-aligned text
- Title Case section headings
- Consistent date format (MM/YYYY)
